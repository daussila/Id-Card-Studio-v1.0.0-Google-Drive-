Access Actions

Counts are best effort, not an audit log: they cover page opens, saved photos, and the Print button (cancelled print dialogs still count). No spreadsheet contents, names, photos, or designs are collected. Disabling or removing access stops future use; it never deletes anyone’s spreadsheets, photos, or designs.

Add users

Paste Google account emails — separated by commas, spaces, or new lines — or import a CSV file. New users get access immediately; no invitation email is sent. Existing accounts keep their current status.

Transfer administrator

The new administrator gets this Control Center. You become a regular user with normal access to Card Studio and Design Studio. They must be able to open this web app.

Using the Control Center

Add users to let them open ID Card Studio. Disable pauses access but keeps them on the list; Remove takes them off the list (their activity history stays until you clear it).

Tick users to act on several at once. Click a name to see activity per card list (each user’s lists are their own). Click a column heading to sort.

Removed users appear only while they still have activity history; Restore gives them access again.

Hide Control Center hides this tab in your browser, e.g. while presenting the app. Press Ctrl + Alt + C (Ctrl + Option + C on a Mac) to show it again.
